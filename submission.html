What the application does

Checks up to 50 pasted addresses and reports likely delivered, likely bounce, or unknown with evidence for each result. Includes searchable results, filters, and a safe CSV export.

Verification scope

The hosted app validates syntax and DNS mail routing, including Null MX and SMTP address fallback. DNS alone cannot confirm a mailbox, so a well-routed address remains unknown. Optional local SMTP checks are limited to operator-owned addresses and never send DATA or a message.

A simulated demo shows all three outcomes using fictional .test addresses. See the repository README for setup, architecture, testing, and hosting limitations.
